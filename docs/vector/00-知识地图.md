# 向量库副线 · 知识地图

> 定位：**广度调研**。工作选型尚未确定，本副线目标是产出一份《向量数据库选型对比报告（运维视角）》，为将来引入提供决策依据。
> 节奏：每周 1-2 小时，与 Doris 主线并行，不抢占主线时间。

## 推进策略

1. **V1 打地基**（约 2 周）：不懂 Embedding 和 ANN，选型对比就是看热闹；
2. **V2+V3 为主战场**：每个候选方案都从**运维视角**过一遍——好不好部署、坏了好不好修、监控全不全、备份怎么做，而不是只比 QPS；
3. **V4 优先深挖 Doris**：如果团队能用 Doris 4.0 内置向量检索覆盖需求，就不必引入新组件——这是对基础设施运维最友好的结果；
4. **V5 收口**：报告结论先行，附对比矩阵与推荐场景，交团队评审后归档。

## 与 Doris 主线的合并点

- 01-架构原理 / 02-部署与变更 学扎实后，Doris 向量检索的上手成本接近于零；
- 选型对比实验全部在本地 Docker 完成，不占用测试机资源。
