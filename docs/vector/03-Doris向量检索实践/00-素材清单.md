## 实验设想（配合实验任务页）

1. 在测试机（4.0.7）建一张带向量列的表，灌入少量 Embedding 数据；
2. 执行相似度检索 SQL，观察是否走向量索引（执行计划）；
3. 与 pgvector / Milvus 做一次小规模延迟对比（同一批数据）；
4. 结论写入 [04-选型对比报告](/vector/04-选型对比报告)。
