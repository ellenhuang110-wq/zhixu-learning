## 运维视角对比维度（写进对比矩阵）

| 维度 | 要回答的问题 |
|------|--------------|
| 部署 | 组件数量？依赖（ZooKeeper/etcd/对象存储）？Docker 单机能否跑？ |
| 高可用 | 副本/选举机制？坏一台怎么办？ |
| 备份恢复 | 有无官方备份工具？能否对接对象存储？ |
| 监控 | 是否暴露 Prometheus 指标？告警生态成熟度？ |
| 资源消耗 | 内存/磁盘基线？索引构建期的资源尖峰？ |
| 学习成本 | 团队现有技能（PG/Doris）能否复用？ |
