## 实验 1：【必做 · 只读】画出你的集群长什么样

- 目标：把第 2 课的 FE/BE 分工，和自己手上的集群对上号
- 前置：任意能连 Doris 的客户端（MySQL 命令行 / DBeaver / DataGrip 均可）
- 步骤：
  1. 执行 `SHOW FRONTENDS;` —— 看有几个 FE、各自角色（Master/Follower/Observer）、Alive 状态
  2. 执行 `SHOW BACKENDS;` —— 看有几个 BE、磁盘容量、Alive 状态
  3. 在纸上或笔记里画出：你的集群有几个节点、谁是谁
- 期望结果：能说出本集群 FE 的角色分布；理解 1FE 的测试机为什么“既是 Master 又是全部”
- 验证方式：指着 SHOW 的结果，向自己（或同事）讲一遍“FE 管什么、BE 管什么”

## 实验 2：【必做 · 只读】解剖一张真实的表

- 目标：把第 3 课的分区 / 分桶 / 副本，在一张真实表上找出来
- 步骤：
  1. 挑测试机上任一张业务表，执行 `SHOW CREATE TABLE 表名;`
  2. 在输出里圈出三样东西：`PARTITION BY`（分区列）、`DISTRIBUTED BY`（分桶列与桶数）、`replication_num`（副本数）
  3. 执行 `SHOW PARTITIONS FROM 表名;` 看看分区列表长什么样
- 期望结果：能说出这张表“按什么分区、按什么分桶、几个副本”
- 验证方式：能解释一句“这张表为什么选这个分区列”（说不出来就回第 3 课找答案）
