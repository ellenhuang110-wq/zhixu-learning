# Doris 主线 · 知识地图

> 生产环境：天翼云 ECS 自建集群，**Apache Doris 4.0.7**，生产运维导向。
> 学习原则：素材标注版本、与官方 4.0 文档冲突时以官方为准；每个主题走完「素材 → 笔记 → 实验 → 自检」闭环再进入下一个；生产集群只读观察。

| # | 主题 | 学什么（一句话） | 关键产出 | 状态 |

| 02 | [部署与变更](/doris/02-部署与变更/00-素材清单) | 部署规划、配置、扩缩容、升级回滚 | 测试机部署 checklist + 升级演练记录 | 未开始 |
| 03 | [监控与可观测](/doris/03-监控与可观测/00-素材清单) | 指标体系、Prometheus/Grafana、审计日志、巡检 | 测试环境监控看板 + 巡检脚本 v1 | 未开始 |

## 三条红线（每个主题都适用）

1. **版本红线**：所有素材标注适用版本，1.x/2.x 内容进入 4.0.7 生产前必须与官方文档核对；
2. **环境红线**：实验只在测试机与本地 Docker 做，生产只读；
3. **闭环红线**：不跳过实验和自检——看懂 ≠ 会做，会做 ≠ 能讲清楚。
