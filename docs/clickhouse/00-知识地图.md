# ClickHouse 学习线 · 知识地图

> 定位：**与 Doris 同赛道的列式分析库，对照学习**。学 CK 不是为了替换 Doris，而是通过对比（MergeTree vs Doris 存储模型、Keeper vs BDB JE）更深地理解两者；CK 的向量检索知识已在向量库副线覆盖，本线聚焦 CK 本体。
> 学习原则：素材标注版本；每个主题走完「素材 → 笔记 → 实验 → 自检」闭环；实验只在本地 Docker / 测试机。

## 与本站其他线的关系

- 与 Doris 主线：每个主题都做一次“CK vs Doris”对照笔记，这是本线最大价值；
- 与向量库副线：CK 向量检索（annindexes）素材在 V2 主题，这里不重复；
- CK 官方文档含**完整中文版**（文档站语言切换 zh）；
- 节奏：不占用 Doris 主线排期，利用间隙推进。

## 三条红线

1. **版本红线**：以官方文档为准（PG 文档按大版本归档，注意切换到所用版本；CK 文档随版本滚动更新）；
2. **环境红线**：实验只在本地 Docker / 测试机，任何生产集群只读观察；
3. **闭环红线**：不跳过实验和自检——看懂 ≠ 会做，会做 ≠ 能讲清楚。
