# 网站使用说明

> 本站是 Doris 与向量数据库的团队学习站点。第一次来的同事，花 5 分钟读完本页即可上手。

## 1. 网站结构

```
首页（你刚看过）
├── 使用说明（本页）
├── 零基础原理课       ← 小白的 35 分钟第一课，从 /learn 进入
├── Doris 主线         ← 主线，按 01→08 顺序学
│   ├── 00-知识地图     ← 每个阶段从这里进入
│   └── 01~08 八大主题
│       ├── 素材清单    ← 看什么材料、看到哪了
│       ├── 学习笔记    ← 中文笔记与操作实录
│       ├── 实验任务    ← 在测试机上亲手做什么
│       └── 自检清单    ← 能讲出来才算学会
├── 向量库副线         ← 每周 1-2 小时推进
│   ├── 00-知识地图（V1~V5）
│   └── 04-选型对比报告（最终产出）
└── 素材总索引         ← 全部素材的汇总台账
```

## 2. 记笔记：网页是橱窗，笔记在文件里

**浏览器里的网站是只读的**——它把笔记文件渲染成好看的网页，但不能直接在网页上打字。

记笔记只需三步：

1. 在编辑器（Qoder / VSCode / 记事本均可）里打开网站源文件目录 `D:\1.Qoder\个人学习网站\docs\`；
2. 找到网页对应的文件——**侧边栏和文件一一对应**：

| 网页上你点的 | 实际编辑的文件 |
|---|---|
| 某主题 → 素材清单 | `docs/doris/主题目录/00-素材清单.md` |
| 某主题 → 学习笔记 | `docs/doris/主题目录/01-学习笔记.md` |
| 某主题 → 实验任务 | `docs/doris/主题目录/02-实验任务.md` |
| 某主题 → 自检清单 | `docs/doris/主题目录/03-自检清单.md` |

3. 写完按 `Ctrl+S` 保存——**浏览器自动刷新**，内容立刻显示在网页上。

三个最常用的写法小抄：

````md
## 2026-10-22 · 素材名    ← 一篇新笔记的开头（二级标题）
- [ ] 待办事项            ← 渲染成可勾选的方框
```sql                   ← 代码块开头（三个反引号+语言名）
SELECT 1;
```                     ← 代码块结尾
````

> 插图：把截图放进 `docs/public/assets/` 目录，笔记里写 `![说明](/assets/文件名.png)` 即可在网页显示。

## 3. 学习方法：一个主题的完整闭环

1. 打开主题的**素材清单**，从推荐度最高的素材开始；
2. 看素材过程中把要点记进**学习笔记**（别只收藏，写下来的才是你的）；
3. 笔记整理完，去**实验任务**在测试机/本地 Docker 亲手做一遍；
4. 最后过**自检清单**，能完整回答的问题打勾，答不上的回到素材定位重学；
5. 三件套全部完成后，回素材清单把状态改为 `已学完`，进入下一主题。

## 4. 状态约定

| 状态 | 含义 |
|------|------|
| `未开始` | 已收录素材，还没学 |
| `学习中` | 正在看或正在整理笔记 |
| `已学完` | 笔记 + 实验 + 自检全部完成 |
| `过时风险` | 素材基于 1.x/2.x 等旧版本，参考时需与官方 4.0 文档核对 |

## 5. 给新人培训怎么用

- 主管：按**知识地图**的顺序给新人排计划，节奏参考知识地图中的里程碑周期；
- 新人：从 `01-架构原理` 开始，每个主题走完上面第 2 节的闭环；
- 考核：自检清单即考核题库，全部打勾即视为该主题合格。

## 6. 如何贡献内容

- **添加素材**：编辑对应主题的 `00-素材清单.md`，按表格追加一行，标注类型/版本/推荐度；
- **写笔记**：笔记写在 `01-学习笔记.md`，用日期 + 素材名做二级标题，一篇讲一个素材；
- **加实验**：实验任务页底部有通用模板，复制后按字段填写；
- **新主题**：复制任意主题目录改名，再在 `docs/.vitepress/config.mts` 的侧边栏数组中注册。

## 7. 本地预览与部署（维护者）

```bash
npm install        # 首次安装依赖
npm run docs:dev   # 本地预览 http://localhost:5173
npm run docs:build # 构建静态文件到 docs/.vitepress/dist
```

把 `dist` 目录部署到内网 Nginx / 任意静态服务器即可，团队浏览器直接访问。

## 8. 安全与合规须知

- 本站内容（含翻译、烧录字幕的视频）**仅限公司内部学习，不对外分发**；
- 所有实验只在天翼云测试机与本地 Docker 执行，**生产集群只读观察**；
- 素材台账中链接的外部视频版权归原作者，站内笔记为学习摘要。
