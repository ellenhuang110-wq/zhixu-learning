# 更新学习进度

> 素材清单里的**状态列**（未开始 / 学习中 / 已学完）就在这里点选更新，不用碰后台文件。
> 选完立即保存，刷新对应素材清单页即可看到变化。

## 什么时候改什么状态

| 状态 | 什么时候设 |
|------|------------|
| 未开始 | 默认值，还没动 |
| 学习中 | 看过一部分（如视频看了几集、文档读了一半） |
| 已学完 | 素材完整过了一遍，且已在笔记里留下要点 |

> 一个主题里**所有素材都是「已学完」**，只是闭环的一半——还要做完实验、自检清单全勾、复习池连续答对 2 次（见[每日学习流程](/guide/学习流程)）。
