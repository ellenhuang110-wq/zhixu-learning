# 自检测验（考考自己）

> 学完一课或一个主题，来这里抽考一次。答不上的题自动进复习池，不会的立刻变成下一步的学习任务。

<QuizPanel />

## 怎么用

1. **看完一课** → 选对应主题，随机抽 5 题（约 5 分钟）；
2. **合上材料** → 先自己讲出来（写几句也行）；
3. 点「对答案」→ 勾选你讲到的关键点 → 自动判分；
4. 低于 60% 的题点「加入复习池」，每天开场抽 3 道复习；
5. 复习池里同一题**连续答对 2 次**会自动移出——这就是"掌握"。

> 60% 以上算及格。一个主题的 8 题全部及格，才算这个主题真正学完（见[每日学习流程](/guide/学习流程)的五条闭环）。
