## 全局素材规范

1. **收录边界**：官方文档全量；视频每主题精选 3-5 个（评分维度：内容深度 > 生产相关性 > 讲解质量 > 播放量）；博客只收一手深度实践文。
2. **版本标注强制**：每条素材必须标注适用版本；与官方 4.0 文档冲突时以官方为准，旧版本独有内容标 `过时风险`。
3. **状态流转**：`未开始 → 学习中 → 已学完`；含旧版本风险的内容可叠加 `过时风险` 标记。
4. **英文素材加工**：英文文章 → AI 翻译 + 术语校对后进笔记；英文视频分级——核心视频下载并烧录中文字幕（存内网），一般视频转写成中文图文笔记。
5. **B 站 412 风控应对**：B 站会对部分访问触发安全风控（错误号 412），并非链接失效。先刷新或登录 B 站账号再试；仍不行则用清单里标注的备用入口（如尚硅谷官网）或 B 站搜索入口按标题检索。
6. **视频时效原则**：官方 2024-2025 新视频（Summit 回放、Webinar、运维实战系列）> 2.x 时代系统课（尚硅谷、黑马等，**只取架构讲法**）> 操作步骤永远以 4.x 官方文档为准。老课不删，但推荐度降到 ⭐⭐ 并标「过时风险」。
