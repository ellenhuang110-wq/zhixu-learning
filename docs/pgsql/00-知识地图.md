# PostgreSQL 学习线 · 知识地图

> 定位：**关系型数据库通用基本功 + pgvector 宿主**。PG 的 SQL/事务/索引/WAL 概念可迁移到几乎所有数据库，是 Doris 之外的“第二语言能力”；同时它是向量选型候选 pgvector 的底座。
> 学习原则：素材标注版本；每个主题走完「素材 → 笔记 → 实验 → 自检」闭环；实验只在本地 Docker / 测试机。

## 与本站其他线的关系

- 与 Doris 主线：对照学习（如 PG 的 WAL 流复制 vs Doris 的多副本多数派），差异点写进笔记；
- 与向量库副线：本线是 pgvector 实验的载体，V2/V4 阶段的 PG 向量实验在这里搭环境；
- 节奏：不占用 Doris 主线排期，利用间隙推进，按需查阅优先。

## 三条红线

1. **版本红线**：以官方文档为准（PG 文档按大版本归档，注意切换到所用版本；CK 文档随版本滚动更新）；
2. **环境红线**：实验只在本地 Docker / 测试机，任何生产集群只读观察；
3. **闭环红线**：不跳过实验和自检——看懂 ≠ 会做，会做 ≠ 能讲清楚。
