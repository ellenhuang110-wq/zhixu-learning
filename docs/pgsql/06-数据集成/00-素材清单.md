## 推荐学习顺序

1. COPY 先练熟（实验 1）
2. 读逻辑复制章节，理解发布/订阅与复制槽
3. 用 FDW 跨两个 Docker 实例查一次
4. 联想：MySQL→Doris 的 CDC 链路与 PG 逻辑复制异曲同工
