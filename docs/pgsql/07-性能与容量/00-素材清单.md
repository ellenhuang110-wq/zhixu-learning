## 推荐学习顺序

1. 读 EXPLAIN 章节并对一条查询做逐节点分析（实验 1）
2. 读 Indexes，给测试表建不同类型索引对比
3. 精读 VACUUM——这是 PG 运维与普通开发拉开差距的地方
4. 膨胀排查案例沉淀到笔记
